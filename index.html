Impersonation Ambiguity as a Security Signal: A Quantitative Framework for Role-Play vs. Malicious Impersonation Detection in Large Language Models

Authors: Abdallah M. Abughallous

Reframed the high inter-judge disagreement on LLM impersonation (98.2% in SemGuard) as a quantitative security signal rather than annotation noise. Introduced the Impersonation Ambiguity Index (IAI) to score inputs across four independent axes: Target Realism, Deceptive Intent, Consent/Context Boundedness, and Downstream Actionability, operationalized as an uncertainty-aware anchor for semantic gateways.

Traceable Autonomy: Identity, Scope Enforcement, and Containment in a Closed-Loop Red/Blue Agent Pipeline

Authors: Abdallah M. Abughallous

This paper presents a concrete pilot study operationalizing the OWASP AIMM framework by enforcing SPIFFE-style identities, strict per-agent scope boundaries, and append-only hash-chained logging across a real, closed-loop Red/Blue AI agent security pipeline. Across 10 non-simulated iterations on a vulnerable Flask/SQLite application, the system achieved a 70% valid patch rate and a 30% containment trigger rate. Notably, the study revealed an emergent finding where automated patching silently broke legitimate app features, proving that traceability alone requires complementary attestation-style validation gates.

30% Containment Trigger Rate
26.6s Mean Latency
100% Hash-Chain Integrity
