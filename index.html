About

I build security tools and research how AI systems get attacked, where application security, security automation and AI agents meet. My IEEE paper SemGuard reached 0.989 mean F1 on a validated Arabic prompt-attack dataset, and my closed-loop Red/Blue agent lab produced the second paper below.

I lead the OWASP Amman Chapter, serve as Section Lead in the OWASP GenAI Security Project, and have a merged contribution in Microsoft PyRIT. I trained at Jordan’s National Cyber Security Center across Red Team, Blue Team and GRC, and I am open to Security Engineer, AppSec and AI Solutions roles where I can build.

Projects

SemGuard

The first multilingual (Arabic, Arabizi, English) LLM security gateway. Triple-Anchor semantic classification with explainable decisions, a validated 807-sample Arabic dataset (Fleiss’ κ = 0.839) and 0.989 mean F1 / 0.991 recall.

Python · NLP · evaluation pipelines

GitHub IEEE paper Awesome AI Security

Autonomous AI Red/Blue Security Lab

Red and Blue agents run real attacks (nmap, sqlmap), patch the code and re-verify with no human in the loop, under SPIFFE-style identities, YAML scope enforcement, a kill-switch and SHA-256 hash-chained logs. Ten real runs: 70% patch-validation success, 100% hash-chain integrity.

Python · Azure AI Foundry · multi-agent systems

GitHub Write-up Paper

ThreatLens

A CLI for fast IOC analysis (IPs, domains, CVEs) over 6 free threat-intelligence APIs, including VirusTotal, Shodan and AbuseIPDB, with color-coded Excel, JSON and CSV output. Listed in Awesome OSINT.

Python · REST APIs · threat intelligence

GitHub Awesome OSINT

TrustGuard AI

Six agents extract policy terms, detect dark patterns, score readability, audit user rights and benchmark privacy policies across GDPR, CCPA, PDPA, PIPEDA, LGPD and DPDPA. Built for Microsoft’s Agents League Hackathon 2026 (Reasoning Agents track).

Flask · Microsoft Foundry · reasoning agents
